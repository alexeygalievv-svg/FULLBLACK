# FULL BLACK — лендинг детейлинг-студии

Одностраничный сайт без сборки и зависимостей: чистые HTML, CSS и JavaScript.
Достаточно открыть `index.html` или залить папку на любой хостинг.

## Структура

```
index.html            разметка и весь текст
assets/css/style.css  стили
assets/js/main.js     интерактив и анимации
assets/img/           фотографии, пары «до/после», эмблема
assets/favicon.svg    иконка вкладки
```

## Что внутри

- **Слайдер «до/после»** — перетаскивание мышью и пальцем, клик по кадру,
  управление стрелками с клавиатуры (`←`/`→`, `Shift` — крупный шаг, `Home`/`End`).
  При первом появлении блока ползунок сам показывает оба состояния.
  Три кейса переключаются вкладками: кузов, салон, покрытие.
- **Анимации** — появление блоков при скролле, вылет заголовка по словам,
  параллакс фотографий, счётчики, бегущая строка, магнитные кнопки,
  свой курсор и превью услуги, которое следует за мышью.
- **Формы** — маска телефона `+7 (999) 999-99-99`, проверка полей, экран «Заявка принята».
- **Доступность** — семантическая разметка, фокус с клавиатуры, ARIA у слайдера,
  полное отключение анимаций при `prefers-reduced-motion`.

## Что нужно заменить перед запуском

1. **Фотографии.** Сейчас в `assets/img/` стоят обезличенные снимки для примера.
   Замените их своими, сохранив имена файлов — вёрстку править не придётся.
   Пары «до/после» должны быть сняты с одной точки и при одном свете:
   `case-body-before.jpg` / `case-body-after.jpg` и так далее, размер 1500×1000.
2. **Тексты кейсов** — в `assets/js/main.js`, объект `CASES` (подпись и срок работ).
3. **Адрес, часы работы, ссылки на мессенджеры** — в блоке «Контакты» в `index.html`.
4. **Отправку формы.** Сейчас заявка никуда не уходит. В `assets/js/main.js`
   найдите комментарий «Здесь подключается отправка на сервер» и добавьте
   свой обработчик — например, отправку в Telegram-бот:

```js
await fetch('https://api.telegram.org/bot<TOKEN>/sendMessage', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    chat_id: '<CHAT_ID>',
    text: 'Заявка: ' + name.value + ', ' + phone.value
  })
});
```

## Локальный просмотр

```bash
python3 -m http.server 4173
# затем открыть http://127.0.0.1:4173
```

Шрифты Onest и JetBrains Mono подключены с Google Fonts.
Без интернета подхватится системный гротеск — вёрстка не поедет.
